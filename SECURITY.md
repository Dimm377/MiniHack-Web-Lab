# Security Policy

MiniHack Web Lab is an educational security project. The default application is expected to remain the secure baseline.

Future exercises may contain intentional vulnerabilities only in isolated, clearly labeled, local-only lab areas. Those training conditions are distinct from accidental vulnerabilities in the baseline.

The v0.2 Phase A HTTP challenges intentionally expose only deterministic per-user training flags through documented request or response behavior. They do not disable baseline security controls.

Please report suspected baseline flaws privately to the repository owner with reproduction steps, impact, and affected version. Do not include real credentials or personal data. Accidental baseline vulnerabilities should be fixed as defects; they should not be reclassified as intentional training behavior.
